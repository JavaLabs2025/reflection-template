# Java Reflection: генератор объектов

Генератор возвращает случайное значение запрошенного типа:

```java
Generator generator = new Generator();
Shape shape = generator.generateValueOfType(Shape.class);
```

Нужна Java 21. Тесты: `./gradlew test`. Пример запуска: `org.example.GenerateExample`.

## Поддерживаемые типы

| Тип | Результат |
|---|---|
| `int`, `long`, `short`, `double`, `float` и обёртки | число из [−1000, 1000] |
| `byte`, `Byte` | любое значение |
| `boolean`, `Boolean` | `true` или `false` |
| `char`, `Character` | символ из `[a-zA-Z0-9]` |
| `String` | 1-10 символов из `[a-zA-Z0-9]` |
| enum | случайная константа |
| массивы, в том числе многомерные | длина 1-5 |
| `List` | `ArrayList`, 1-5 элементов |
| `Map` | `HashMap`, 1-5 пар |
| класс или record с `@Generatable` | объект, созданный случайным public-конструктором |
| интерфейс или абстрактный класс с `@Generatable` | объект случайной помеченной реализации |

Типы элементов берутся из generic-параметров конструктора. для `List<Product>` генерируются `Product`. у `List` и `Map` без параметров элементы `Integer` и пары `String / Integer`. Для `? extends X` и `? super X` генерируется `X`.

## Аннотация `@Generatable`

- Нужна каждому пользовательскому типу - классу, record, интерфейсу, абстрактному классу. Без неё генерация падает с `GenerationException`
- **Класс** создаётся через случайный public-конструктор, аргументы генерируются рекурсивно по типам параметров.
- **Интерфейс или абстрактный класс.** Генератор ищет в его пакете и подпакетах конкретные классы, которые его реализуют и сами помечены `@Generatable`, и выбирает один случайно. Непомеченные реализации не выбираются никогда, если подходящих нет, бросается исключение.
- **Не наследуется.** Аннотация на `Shape` не делает генерируемыми `Rectangle` и `Triangle`
- Встроенным типам из таблицы аннотация не нужна

## Рекурсия

Объекты создаются не глубже 5 уровней вложенности. Глубже ссылка на объект получает `null`, а коллекции и массивы получаются пустыми. Поэтому у листьев `BinaryTreeNode` поля `left` и `right` равны `null`

## Ошибки

Если значение создать нельзя, бросается `GenerationException`. В сообщении указаны причина и место. Например, если снять аннотацию с `Product`

```
Cannot generate parameter 'items' of org.example.classes.Cart: org.example.classes.Product is not annotated with @Generatable
```

Исключение бросается в таких случаях: `void`, тип без `@Generatable`, нет помеченных реализаций, нет public-конструктора, пустой enum, неподдерживаемый тип (`Object`, `Set`, `Box<T>`), исключение в конструкторе, неверный `@Range`.

## Предметные ограничения

1. `@Range(min, max)` на параметре конструктора - число сразу генерируется в диапазоне. Для целых типов это [min, max], для дробных - [min, max).
2. Ограничения между параметрами проверяет сам конструктор и бросает `IllegalArgumentException`. Генератор тогда подбирает новые аргументы, до 1000 попыток. Другие исключения из конструктора не повторяются

У `Rectangle` стороны помечены `@Range(min = 1, max = 100)`, а конструктор проверяет, что они положительные. У `Triangle` такие же стороны, а конструктор проверяет неравенство треугольника. В среднем на треугольник уходит около 2 попыток, без `@Range` было бы около 16.

## Ограничения

- Из коллекций поддерживаются только `List` и `Map`. `Set` или `ArrayList` в качестве типа параметра не поддерживаются.
- Generic-классы пользователя (`Box<T>`) и generic-массивы (`T[]`) не поддерживаются
- Используются только public-конструкторы. Фабричные методы и прямое заполнение полей не применяются.
- Реализации ищутся только в пакете интерфейса и его подпакетах, только в каталогах classpath, не в jar.
- Предел глубины 5 обрезает и длинные нерекурсивные цепочки объектов.
- `@Range` работает только с числовыми параметрами, границы - целые числа.
- `Generator` не потокобезопасен.

## Тесты и CI

Тесты на JUnit 5 лежат в `GeneratorTest`. Они проверяют:
- все категории типов;
- шаблонные и собственные классы;
- `Shape.class` и абстрактный класс;
- семантику `@Generatable`;
- ошибки;
- `@Range` и предметные ограничения;
- seed.
